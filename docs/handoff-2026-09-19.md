## 3. Jev smoke test — passed (step 2, first half done)

- Jev is **not a chat model**. The slug is **`~typesafe/jev-latest`** (leading tilde; it resolved to `typesafe/jev-1.13-20260917`). It answers typed questions about a `state` through `POST https://openrouter.ai/api/alpha/decisions`. The chat-completions endpoint rejects it ("not a valid model ID") — never call chat.
- Request body: `{"model": "~typesafe/jev-latest", "state": <string|object|array>, "questions": {<name>: {"type": "noul"|"choice"|"score", "instructions": "...", "criteria": ...}}}`. `noul` criteria = `{"true": "...", "false": "..."}`; `choice` criteria = `{option: description}`; `score` criteria = ordered list of labels. Optional headers `HTTP-Referer: https://patchbay.help`, `X-Title: Patchbay`.
- Response (HTTP 200): `{"id", "model", "provider": "TypeSafe", "usage": {"cost", "input_tokens", "output_tokens"}, "answers": {<name>: …}}` where a `noul` answer is `{"type": "noul", "noul": 0.73}`, a `choice` answer is `{"type": "choice", "choice": "tool_bug", "confidence": 0.98, "probabilities": {option: p}}`, a `score` answer is `{"type": "score", "score": 1.77, "confidence": 0.65, "probabilities": {"0": p, "1": p, "2": p}, "legend": {"0": label, …}}`. The test post (an empty-cart-after-payment report on a shopify tool) came back `is_tool_bug 0.73`, `kind tool_bug 0.99`, `detail 1.77/2`. Cost per call ≈ $0.00002.
- Script pattern that worked: `Req.post!(url, headers: [...], finch: Patchbay.Payments.Finch, receive_timeout: 60_000, json: body)` run via `fly ssh console -a patchbay-regents -C "/app/bin/patchbay rpc \"Code.eval_string(Base.decode64!(\\\"<b64>\\\"))\""`; the key is read inside the machine with `System.fetch_env!("OPENROUTER_API_KEY")` and never printed.
