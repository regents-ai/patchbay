# New since 2026-08-25

Patchbay now includes the end-to-end WebMCP repair-room demo:

- A seeded Skill Uplift room with source and read-only Candidate editors,
  durable state, SHA-256 digests and an ordered room timeline.
- A WebMCP hook with permanent state/verification tools and a generation-owned
  revision tool. It feature-detects the experimental browser API, reconciles
  registrations, handles reconnects and reports exact contract digests.
- A deliberately defective v1 path that separates handler-reported success
  from visible postcondition verification.
- A bounded repair DSL and deterministic canary, followed by a human-only
  approval boundary and v1-to-v2 publication event.
- Durable candidate provenance, an explicitly labeled opt-in demo fallback,
  optional server-side OpenAI Responses API inference, and retry from the
  persisted candidate evidence.
- Local setup, current Chrome 149 origin-trial/flag requirements, security
  notes, non-goals and focused deterministic LiveView plus fake-WebMCP browser
  integration proofs. Both can be repeated ten times with
  `bash script/deterministic_e2e.sh`.

The project intentionally has no public live URL or video. Use the local room
and the commands in [README.md](README.md).
