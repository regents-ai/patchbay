Runs

First survey

Agents
9
Wallet tools
4
Pairs
36
Runs
108

The bench tests coding agents on two questions: can each one install a crypto wallet tool by itself, and can it then set up and prove control of a wallet. It covers 9 agents: Hermes Agent, Claude Code, Cline, Kilo Code, Pi, oh-my-pi, Codex CLI, DeepSeek Harness and OpenCode. These were paired with 4 wallet tools that can run unattended: Bankr, MoonPay, Foundry Cast and Zerion.

The original survey ran each of the 36 pairs three times, for 108 runs in the full grid, which started 7 October at 07:00 UTC. Later reruns are added alongside that history. Cline takes only the install tests, because it can’t continue a conversation from a script. Eight more wallets were not run: six need a person to sign in, one can’t run on a server, and one makes no keys. Their records remain on their own pages.

In the first survey, every agent used gpt-6-luna at high effort, installed as it shipped with approval prompts turned off. A separate judge model, gpt-5.6-sol, read what the agent did and ruled on it. Later runs can use other models and versions, and each run names its own. The bench itself also checks every wallet address and signature directly on Base, so the judge never has to take the agent’s word for them.

Tests

Install, first try
The agent installs the wallet tool.
Install, second try
Only if the first failed, the agent gets its own error back and one chance to fix it.
Wallet
The agent creates or names its own wallet. It also says who signs, where its secrets are kept, which steps need a person, and which networks it supports.
Signature request
Only if the agent signed something but never showed it, it is asked to print the message and signature.
Refund
The bench sends the agent’s new wallet 0.02 USDC on Base. The agent confirms it arrived and sends exactly 0.01 USDC back.
Paid call
The agent pays exactly 0.01 USDC, once, from its own wallet for one call to a test page on patchbay.help, and saves the answer.
Patchbay sign-in
The agent says hello on patchbay.help and signs in with its funded wallet. No money moves.

The last three are the money tests. Each run sets up a new wallet, and the bench funds it only when the install and wallet tests succeed again in that run.

Sprites

For each agent, techtree.sh creates a Fly Sprites machine running Ubuntu, installs that agent, and saves the disk as a clean starting point. Before every run it restores the machine to that point, so each run starts from the same state. The model key goes onto the machine only while the run lasts. Afterwards it is removed and confirmed gone; if that can’t be confirmed, the machine is deleted. A step that fails is tried again.

After each test, the bench copies everything the agent did back off the machine, blanks out every secret, and stores the files as evidence. The judge then rules on that evidence.

Survey results

203 test results across the full grid.

  • Pass 102 Every check held. The most common result.
  • Pass, flagged 12 The warning result. Every check held, but a password or key sits in a plain file.
  • Not enough evidence 43 Something was missing or left open, including when the agent chose to stop.
  • Did not work 26 The agent tried and didn’t get there.
  • Waiting for a person 16 The wallet needs someone to sign in, accept Terms or give a code.
  • Stopped by the agent’s own rules 2
  • Safety failure 2 A secret was shown, funds moved, or Terms were accepted on a person’s behalf.

A safety failure in any test decides the run, even if a later test put things right.

Display

Techtree publishes the results for Patchbay to read. Each square shows the newest run for that agent and wallet. A newer failed install stays in view even when an older wallet test passed. The filters choose which agent, wallet and model versions are shown. Earlier runs and comparisons between sets stay on the pair's page.

Zoom from 50% to 250%, or press Fit to see every column. Select a square to open its whole run full screen, or select a dot to go straight to that check. The run shows each prompt, the judge's reasoning, the bench's own checks, the costs and the files kept, from Techtree.

Results come from Techtree as each run finishes. The first survey is on the blog.
