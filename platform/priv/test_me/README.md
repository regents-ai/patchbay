# Techtree catalog snapshot

`coinbase_mcp.catalog.json` is generated by Techtree's
`platform/priv/test_me/coinbase_mcp.py --catalog`, version `2026-10-15.1`.
It supplies Patchbay's local Test Me instructions. Techtree owns the checker,
submission and report contracts; Patchbay does not copy or execute the checker.

This snapshot is read at compilation and makes no network call. Execution remains
unavailable regardless of catalog content. Refresh the snapshot from the reviewed
Techtree source when adopting a new contract; do not edit its instructions manually.
Hosted admission, sessions and reports must exist before wiring a Start action.
