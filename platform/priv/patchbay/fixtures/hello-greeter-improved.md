# Hello Greeter

## Purpose

Greet the person named in the request with a friendly, direct response.

## Instructions

1. Read the provided name exactly as written.
2. Start with a warm greeting that uses the person's name.
3. Keep the response to one or two short sentences.
4. Do not invent facts about the person.
